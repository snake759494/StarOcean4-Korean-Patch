# 스타오션 4 THE LAST HOPE 4K & Full HD Remaster 한글 패치

Steam판 **STAR OCEAN - THE LAST HOPE - 4K & Full HD Remaster** (App 609150)용 비공식 한글 패치입니다.
게임의 **일본어** 언어 슬롯을 한국어로 바꿉니다.

## 번역 범위
- 스토리 컷신 자막 105개 장면 전체 (오프닝 포함)
- 메뉴, 시스템 메시지, 튜토리얼, 도움말 창
- 아이템·스킬·무기·방어구·몬스터 이름과 설명, 퀘스트, 배틀 컬렉션
- 프라이빗 액션(PA) 및 NPC 대사
- 글꼴: 나눔스퀘어 네오 Bold

원문 유지: 엔딩 스태프롤, 전투 연출용 영문 장식 글자, 일부 드문 시스템 문구.
모든 번역은 일본어 원문을 기준으로 직접 번역했으며 기계번역은 사용하지 않았습니다.

## 설치
1. 게임을 종료합니다. (처음 설치라면 Steam에서 "게임 파일 무결성 확인"을 한 번 해 두는 것을 권장합니다.)
2. [Releases](../../releases)에서 `StarOcean4_KoreanPatch.exe`를 받아 실행합니다.
3. 게임 폴더를 자동으로 찾습니다. 다른 위치에 설치했다면 경로를 입력하세요.
4. 완료 후 게임 설정에서 **텍스트 언어를 일본어**로 선택합니다.

- 적용 전에 원본 데이터를 검증하므로, 게임 버전이 다르면 아무것도 쓰지 않고 중단합니다.
- 게임 파일이 약 0.8GB 늘어납니다.

## 제거
Steam 라이브러리 → 게임 속성 → 설치된 파일 → **게임 파일 무결성 확인**.

## 알려진 문제
- 일부 메뉴에서 캐릭터 이름이 일본어로 표시될 수 있습니다.
- 프랑스어·독일어 등 다른 언어로 플레이할 때는 영향이 없습니다(일본어 슬롯만 변경).

## 개발자용
패치는 `build_reloc.py`로 빌드하고 `export_release.py`로 배포용 차분을 만듭니다.
작업 원칙과 포맷 정보는 [AGENTS.md](AGENTS.md), 용어는 [localization/GLOSSARY.md](localization/GLOSSARY.md)를 참고하세요.
이 저장소에는 게임에서 추출한 데이터가 들어 있지 않습니다. 빌드하려면 본인이 소유한 게임에서 추출 도구(`tools/`)로 원문을 먼저 생성해야 합니다.
